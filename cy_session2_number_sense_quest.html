Session Goal

Help Cy strengthen the bridge between physical quantities and abstract number representations, using blocks first and then gradually reducing support.

Core Move

Build it → describe it → draw it → write it with numbers → predict the next step without building.

60-Minute Flow

0–8: Reset + quick win
8–20: Finish Session 1 work
20–38: Build → Draw → Write
38–50: Find My Rule
50–57: Stretch challenge
57–60: Success close

Opening Script

“Today is a quest. The goal is not just getting answers. The goal is learning how the same idea can show up as blocks, a picture, numbers, and a rule.”

🌱 Finish Session 1

Use these to complete prior work and assess whether he can explain the relationship between blocks and numbers.

🧱 Build → Draw → Write

For each item: build the first 3 steps, draw them quickly, write the number sequence, then predict the next number.
