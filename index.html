Session 2: Number Sense Quest

Cy works through a live adventure that connects concrete manipulatives, visual models, and abstract number sentences. This mission strengthens the bridge between physical math and symbolic math.

  • 🧱 Build with blocks or counters
  • 🗺️ Draw the mathematical model
  • 📜 Write the number sentence
  • 🔍 Find and explain pattern rules
  • ⚔️ Complete a Boss Battle mastery challenge
