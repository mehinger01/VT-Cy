Reading Forest: Three-Pass Strategy

Passage: Building With Coordinates

Builders often use coordinate systems to describe exact locations. On a coordinate plane, the x-coordinate tells how far to move left or right, while the y-coordinate tells how far to move up or down. This makes it possible to reproduce a design accurately.

Coordinate systems also help programmers place objects in games. A character, building, or item can be assigned a location using numbers. When one coordinate changes, the object moves in a predictable direction.

Because coordinates describe location precisely, they connect mathematics, design, engineering, mapping, and game development.
